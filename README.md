# Python 對接 MongoDB Atlas 雲端資料庫模組

本專案為一個完整的 **Python 資料庫連線模組**，實作了如何安全、穩健地串接 **MongoDB Atlas (雲端 NoSQL 資料庫)**，並進行自動化資料檢索、統計與健全度檢查。

## 🛠️ 技術亮點
* **環境變數配置**：採用 `MONGO_URI` 外部環境變數設定，避免密碼明文外洩，符合業界資安規範。
* **高可用防錯機制**：內建 `ConnectionFailure` 與異常捕獲 (try-except)，能自動診斷 IP 白名單未設定或帳密錯誤等連線問題。
* **自動化資料遍歷**：利用遊標 (Cursor) 機制實作低記憶體消耗的資料逐筆撈取，並自動進行精確的資料筆數統計。

## 📋 執行流程
1. 讀取系統環境變數驗證資料庫憑證。
2. 對雲端資料庫發送 `ping` 指令進行健康檢查。
3. 成功連線後，自動撈取指定資料集 (Collection) 並輸出筆數摘要。
