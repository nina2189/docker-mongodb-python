**🏢 步驟一：在公司電腦建立環境（第一天）**

打開公司發給你的電腦：安裝好 python、Git 和 Docker Desktop。

獲取公司的測試資料庫網址：主管會給你一串公司研發專用（Development）的 MongoDB 連線字串。

(上面提到的字串是:操作流程裡面的執行指令docker run --rm -e MONGO\_URI="主管給的字串" my-mongo-app)

設定白名單：這時需要把公司辦公室的外網 IP 加進公司的 MongoDB Atlas 白名單中（通常公司的網管工程師會事先設定好）。



**💻 步驟二：從零開始編寫與打包（開發階段）**

在公司電腦新增一個資料夾，寫好 app.py、requirements.txt 和 Dockerfile。

在公司電腦的終端機（CMD 或 Terminal）輸入：

docker build -t company-project:v1.0 .

在公司電腦輸入 docker run ...(執行指令可以看操作流程)，帶入主管給你的測試庫網址，確認程式能成功寫入資料



**🚀 步驟三：將程式碼與產品上傳（交付階段）**

在公司裡，你寫好的代碼(就是app.py)和打包好的貨櫃，必須上傳到公司的中央管理系統，而不是留在你個人的電腦裡。這裡會分為兩條線同時上傳：



路線 A：上傳「程式原始碼」

公司不會讓你用隨身碟拷貝，而是使用 Git 工具。

你會輸入指令（如 git push），把你的 app.py、Dockerfile 上傳到公司的程式碼倉庫（例如 GitHub 或 GitLab 的公司企業分帳號）。



路線 B：上傳「Docker 貨櫃成品」

你會在終端機輸入：

**docker tag company-project:v1.0 公司帳號/company-project:v1.0**

**docker push 公司帳號/company-project:v1.0**

這會把你的貨櫃成品推送到公司的 Docker 倉庫（如 Docker Hub 企業版、AWS ECR 等）。



**☁️ 步驟四：正式部署上線（上線階段）**

上傳完成後，你（或公司的維運工程師）會登入公司的雲端正式伺服器。

伺服器會直接從公司的 Docker 倉庫把 公司帳號/company-project:v1.0 下載下來。

啟動時，帶入公司最機密的「正式營運資料庫（Production DB）」連線網址：

**docker run -d -e MONGO\_URI="公司的正式庫網址" 公司帳號/company-project:v1.0**

這樣客戶就能開始使用你寫的網站或服務了！
